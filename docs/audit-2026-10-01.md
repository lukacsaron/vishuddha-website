# Technical SEO and UX audit — 2026-10-01

Run against a production build on a local server, in Chrome, at 320, 360, 390, 768,
1024, 1280, 1440 and 1920 px wide, plus a phone in landscape. The live site was
behind the coming soon page at the time, so nothing here is field data: no Core Web
Vitals from real visitors, no Search Console, and no Safari or physical devices.

## Result

No critical problems. One real defect was found and fixed (header cut off on narrow
phones). Everything fixable in code was fixed, in two passes; what remains needs
material only the owners have.

| Area | Status | Notes |
|---|---|---|
| Crawlability | pass | robots.txt and sitemap correct; all content is in the server HTML |
| Indexability | pass | canonical, hreflang, noindex where intended, real 404 |
| Security | pass | HTTPS, HSTS, CSP, frame, sniffing and referrer headers |
| URL structure | pass | clean URLs, single-hop redirects, www → apex |
| Mobile | pass after fix | no horizontal scroll at any width; header fixed at ≤360px |
| Performance | pass (lab) | layout shift 0; 600 KB before the hero video |
| Structured data | pass | LocalBusiness JSON-LD in the server HTML |
| Accessibility | pass | contrast, tap targets, focus, reduced motion |

## Fixed in this pass

1. **Header cut off on small phones.** At 360 px and below (most Android phones) the
   Contact button ran off the right edge. The logo and spacing now shrink at ≤400 px.
2. **Menu links landed under the header.** Sections now stop just below it.
3. **Low-contrast small text.** Menu links, the inactive language, footer headings
   and the copyright line were between 3.3:1 and 4.2:1 on brand blue. Raised to 4.5:1
   (white at 62% instead of 45–55%).
4. **Small tap targets.** Language switch (32×22 px), header button and footer links
   get a larger invisible hit area on touch screens. Their look is unchanged.
5. **No page landmark.** Content is now inside `<main>`.
6. **Video lightbox.** Announced as a dialog; focus moves to the close button and
   returns to the tile on close.
7. **Reduced motion.** Visitors who ask their system for less motion get no
   autoplaying video, no marquee, no slide-in effects.
8. **Keyboard focus** is visible everywhere (white outline).
9. **404 page.** Unknown addresses got a bare framework page; now a branded one in
   the right language, still answering 404.
10. **Security headers.** Added `Strict-Transport-Security` and a
    `Content-Security-Policy` that allows only the site's own scripts plus the
    YouTube player. Verified with zero violations on the site and in the admin.
11. **Phone home-screen icon and browser theme colour** added.
12. **Mobile hero.** A vertical video and poster can be set for phones, so the
    landscape clip is no longer cropped to a sliver.

## Fixed in a second pass, on request

13. **Mobile menu.** Below 1100 px a menu button opens Services / Work / Team /
    Contact plus the phone number and email. It closes on a link, on Escape and on a
    tap outside. Under 480 px the header's Contact button moves into the menu.
14. **Title and description shortened** to 60 and 143 characters, and both now say
    "micro-production company", matching the page. These are the built-in defaults:
    a site whose texts were already saved keeps its own until edited under
    Search and sharing.
15. **Empty gallery slots are no longer shown to visitors.** They stay in the admin
    as reminders; a slot appears on the site once it has a photo or a video.
16. **A service without a photo** shows its text across the full width instead of
    an empty dashed box.
17. **Legal links appear in the footer only for pages that have text.**
18. **Button red** is `#d34138` (4.58:1 under white text) instead of the brand
    `#dc443a` (4.26:1). Button fills only; labels and accents keep the brand red.
19. **No text under 11 px** any more.
20. **Preloader hold cut from 1.2 s to 0.5 s**, and its safety cap from 4 s to 2.5 s.
21. **Vertical hero clip for phones**, cut from the landscape one: the same picture
    phones were already showing, at 1.3 MB instead of 4.4 MB.
22. **`/hu` redirects to `/hu/`**, so the page has one address.
23. **The keywords meta tag is gone**, along with its field in the admin.

## Still open

1. **Photos and texts only the owners have:** the Photography photo, gallery
   photos, Privacy Policy and Terms, a street address for local search.
2. **Images in `/media/` are revalidated on each visit** rather than cached for a
   long time. They are not content-hashed, so a long cache would keep showing an
   old logo after it is replaced. The cost is one small "not modified" answer per
   file. Hashed CSS and JS, and everything uploaded in the admin, are cached for a year.
3. **AI crawlers are allowed** in robots.txt. That is a choice, not a defect:
   allowing them favours being cited by AI search.
4. **Safari and physical devices** were not tested.

## How to re-check after launch

Once the coming soon page is off: run the address through PageSpeed Insights for
real Core Web Vitals, submit `https://vishuddhaproductions.com/sitemap.xml` in
Google Search Console, and test on an actual iPhone (Safari handles autoplaying
video and the vertical-video switch slightly differently from Chrome).
